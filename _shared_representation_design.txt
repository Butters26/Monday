ARCHITECTURAL OWNERSHIP
===============================================================================
SharedRepresentation OWNS:
  - Stable concept identity (concept_id for life of store)
  - Canonical names + deliberate aliases (dog/dogs → same; no fuzzy merge)
  - Structured relationships: source, target, type, strength/confidence
  - Activation state + bounded spreading activation (decay, depth/node caps)
  - Common concept envelope for handoff
  - Global vs user-scoped personal association edges (no cross-user leak)

SharedRepresentation does NOT own:
  - Pattern discovery (co_occurrence / sequences stay in Pattern)
  - Reasoning conclusions / grounded meaning composition
  - Attention focus / salience ranking
  - Emotion affect / PAD
  - Notus memory DB (facts, episodes, conversations)
  - Language wording / Output delivery
  - MetaCognition epistemic watch / MetaAwareness process mode
  - Executive goals / Motor actions / Voice synthesis
  - Learning stack / Experience / Beliefs / BehavioralReinforcement

===============================================================================
GLOBAL vs USER MODEL
===============================================================================
GLOBAL:
  - Concept identity (concept_id, canonical_name, aliases, concept_type,
    properties) — shared across users ("dog" is the same concept for Alice/Bob)
  - Global relationships (is_a, similar_to, etc.) — shared semantic structure
USER-SCOPED:
  - Personal association edges keyed by user_id (e.g. Alice's dog→fluffy)
  - Retrieved only when that user_id is supplied
  - Alice's personal edge MUST NOT appear in Bob's get_relationships /
    spreading that includes personal edges
Spreading on live path: uses global edges + optional personal edges for the
  active user_id only.

===============================================================================
SCHEMA (cleaner than old Concept)
===============================================================================
Concept:
  concept_id: str          # stable, e.g. c_<hex> — never reused / reassigned
  canonical_name: str      # lowercase canonical surface
  aliases: list[str]       # deliberate aliases (plural forms, synonyms we add)
  concept_type: str        # object|action|emotion|abstract|relation|unknown
  properties: dict
  created_at / updated_at: float
  activation: float        # ephemeral, not a durable identity field

Relationship (structured, not strings):
  source_id: str
  target_id: str
  rel_type: str            # is_a | has_property | causes | similar_to |
                           # opposite_of | associated_with | personal_assoc
  strength: float          # 0..1 confidence/weight
  scope: "global" | "user"
  user_id: str | None      # required when scope=user
  created_at: float

Identity / canonicalization (deliberate, NOT fuzzy):
  - lowercase, strip punctuation
  - simple English plural fold: dogs→dog, boxes→box, categories→category
  - exact alias lookup only
  - NEVER merge by edit-distance / embedding similarity
  - never-seen terms create NEW concepts (honest; no giant toy dictionary)

Spreading activation (bounded, testable):
  - BFS from seeds with max_depth, max_nodes, per-hop decay, threshold
  - No recursion runaway; deterministic visit order (sorted edge keys)
  - decay_all / reset_activation for turn boundaries
  - Semantic availability ≠ Attention focus
