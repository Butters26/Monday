# Brain Control Interface

## 🎨 Features

**3D Visual Design**
- Gradient backgrounds with depth
- Drop shadows and glow effects
- Smooth animations
- Modern glass-morphism style

**Real-Time Monitoring**
- Live status for each brain lobe
- Activity level indicators
- Neural connection visualization
- Pulsing status dots

**Interactive Controls**
- Send thoughts/commands to the brain
- Individual lobe interaction buttons
- System-wide status display

## 🚀 How to Launch

### Option 1: Using the launcher
```bash
./launch_interface.sh
```

### Option 2: Direct launch
```bash
python3 brain_interface.py
```

## 📊 Interface Layout

**Header** - Main title with glowing effect

**Neural Connections** - Animated visualization of lobe communication

**Lobe Widgets** (Grid of 7 lobes)
- Representation Layer (Purple)
- Pattern Recognition (Orange)
- Reasoning (Blue)
- Notus Memory (Green)
- Emotional Engine (Pink)
- Perception (Cyan)
- Output (Gold)

Each widget shows:
- Status (online/offline with pulsing indicator)
- Activity level percentage
- Current stats
- Interact button

**Control Panel** - Bottom input bar for sending commands

## 💡 Tips

- Launch the brain system first (python3 start_brain.py) for full functionality
- Interface works in "demo mode" even if lobes aren't running
- Resize window to see full layout
- Each lobe has its own color theme for easy identification
