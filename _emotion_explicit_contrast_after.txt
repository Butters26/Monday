=== Emotion explicit/contrast — before/after notes ===
Date: Sat Sep 19, 2026 (America/Denver)
embedding model_type=basic

PRIORITY PRESERVED: AppraisalEngine -> semantic support -> keyword/cue fallback

## What changed
1) Basic semantic authority limited
   - model_type=basic: primary eligibility bar raised (0.58); candidates still reported.
   - When AppraisalEngine is authoritative (strong OR contrast-authored), semantic may
     SUPPORT only if event AGREES; conflicts are IGNORE (semantic_used=False).
   - Basic semantic must not override confident appraisal (I'm furious/sad/worried).

2) Explicit self-report vs appraisal event separated
   - _extract_explicit_user_emotion reads I'm happy/angry/sad/scared/relieved/proud
     (with negation/contrast). Sets user emotion independently of event_type.
   - event_inferred_emotion keeps event→emotion mapping (e.g. success→proud).
   - Example: 'I'm really happy with how that turned out' → user=happy, event=success.

3) Relieved
   - Added EmotionalState.RELIEVED with PAD (0.55, -0.25, 0.35).
   - Not silently mapped to proud; success appraisal may still exist separately.

4) Contrast
   - Clause after 'but' / current-state outranks earlier/hypothetical affect for USER emotion.
   - Contrast-authored results are appraisal-authoritative so noisy basic semantic cannot fill.
   - Additive 'but I'm exhausted' does not override prior proud (exhausted not an emotion state).

5) Negation preserved
   - I'm not angry / I'm not sad anymore / It's not unfair → neutral.

## Remaining weak cases
- Basic embeddings still propose noisy candidates (e.g. I'm scared → unfairness); gated off, but ST would help paraphrases.
- 'I'm proud of finishing it, but I'm exhausted': exhausted is not an EmotionalState; proud kept (additive contrast).
- 'I actually pulled it off' still maps user emotion via success→proud (no explicit self-report word).
- Soft event for bare 'I'm happy.' is affection (not celebration); acceptable separation of emotion vs event.
- Keyword cue list intentionally not expanded; paraphrases without appraisal/ST may still ALL_ZEROS on cues.
