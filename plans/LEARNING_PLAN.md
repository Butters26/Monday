# Monday Learning Plan (Matthew's plan, Nov 12, 2026)

**This plan waits.** It starts only once every lobe is done, the team works (`plans/BUILD_PLAN.md` finished), and she has been running that way for a while (Matthew, Oct 30 and Nov 12). Do not start learning work before then.
Live copy: Part 4 of the "Monday Build Plan" doc (https://claude.ai/artifact/3sJaBEDJ5LSLeQkoBdCTes). The kinds of learning and open decisions are on the "Monday Learning List" doc (https://claude.ai/artifact/8qa1RYmnkG9TPTrJDhSKX7).

Each lobe learns its own job better, using the eleven kinds of learning on the Learning List: consequences, being corrected, being told, watching, practice, generalizing, evolution (the game), curiosity, resting, association, getting used to things. They feed one brain; they aren't separate machines.

| Lobe | What it learns | Kinds of learning |
| --- | --- | --- |
| Language | Words, meanings, sentence shapes, how Matthew phrases things | Being told, being corrected, watching, practice, generalizing, evolution (the game) |
| Reasoning | Which conclusions hold up; which beliefs to trust more or less | Consequences, being corrected, generalizing |
| Notus | What's worth keeping strong; what goes with what | Practice (stronger with use), resting (replay), association |
| Executive Control | Which choices work in which situations | Consequences, practice, being corrected |
| Attention | What deserves focus; what to stop noticing | Getting used to things, consequences |
| Novelty | What's no longer new; which gaps to ask about | Getting used to things, curiosity |
| Pattern Recognition | Which repeats are real | Association, generalizing |
| Social Context | What social moves mean and expect | Being told (Matthew's social beliefs), being corrected, watching, consequences |
| Conversation | How exchanges usually go | Watching, practice |
| Metacognition | Which checks catch real mistakes | Consequences |
| Values | What matters more or less to her | Consequences (old and new strength always kept) |
| Motor Action, Output, Voice | Doing and delivering more smoothly | Practice, being corrected |
| Autonomous Thinking | What's worth thinking about while idle | Resting (replaying the day), curiosity |
| Autonomous Speech | When bringing something up is welcome | Consequences |
| Emotion | Feelings tied to what happened; calming to the familiar | Association, getting used to things |
